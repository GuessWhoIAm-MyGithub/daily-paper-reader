## 摘要
图像哈希提供紧凑的表示以实现高效存储和检索，但固有地局限于全局比较，无法推理变化发生的位置。这一局限性阻止了哈希直接应用于场景变化检测，其中空间定位至关重要。在本工作中，我们从场景变化检测的角度重新审视哈希，并提出HashSCD，一个补丁级哈希框架，既支持高效的全局变化检测，又支持局部化变化识别。HashSCD将空间对齐的补丁编码为紧凑的哈希码，并通过类似XOR的操作聚合它们，从而允许在哈明空间中直接进行变化检测和定位，无需对先前图像进行重复推理。该模型通过对比学习在补丁和全局两个层面以无监督方式进行训练。实验表明，与最先进的无监督哈希和场景变化检测方法相比，HashSCD在性能上具有竞争力，同时显著降低了计算成本和存储需求。

## Abstract
Image hashing provides compact representations for efficient storage and retrieval but is inherently limited to global comparison and cannot reason about where changes occur. This limitation prevents hashing from being directly applicable to scene change detection, where spatial localization is essential. In this work, we revisit hashing from a scene change detection perspective and propose HashSCD, a patch-wise hashing framework that enables both efficient global change detection and localized change identification. HashSCD encodes spatially aligned patches into compact hash codes and aggregates them through an XOR-like operation, allowing change detection and localization to be performed directly in the Hamming space without repeated inference on previous images. The model is trained in an unsupervised manner using contrastive learning at both patch and global levels. Experiments demonstrate that HashSCD achieves competitive performance compared to state-of-the-art unsupervised hashing and scene change detection methods, while significantly reducing computational cost and storage requirements.

## 1. 核心问题与整体含义
*   **研究背景与动机**：场景变化检测（SCD）是长期监控的关键任务，要求高效检测并定位场景随时间的变化。现有基于深度特征的方法虽然有效，但需要存储高维浮点特征或对历史图像进行重复推理，计算和存储开销大，限制了可扩展性。另一方面，图像哈希技术能生成紧凑的二进制码，实现快速检索和低存储成本，但传统哈希仅进行全局图像比较，无法定位变化区域，因此无法直接应用于需要空间定位的场景变化检测任务。
*   **核心问题**：**能否将哈希的效率优势应用于场景变化检测，同时支持变化的局部化定位？**

## 2. 提出的方法论
*   **核心思想**：提出 **HashSCD** 框架，首次将哈希引入场景变化检测。通过**补丁级哈希**和**类XOR聚合操作**，在保留哈希效率（紧凑二进制码、汉明空间快速比较）的同时，实现变化检测与空间定位。
*   **关键技术细节**：
    1.  **补丁级哈希嵌入**：将图像通过骨干网络（如VGG16）提取的特征图划分为P个空间补丁，每个补丁的特征通过一个可学习的投影矩阵映射为长度为l的哈希码。
    2.  **类XOR聚合操作**：将所有补丁的哈希码通过一个递归的绝对差值操作进行聚合（在二进制域等价于级联XOR），生成一个**全局哈希码**。这个操作既保留了所有局部信息，又将表示压缩为固定长度，克服了传统全局哈希无法反映局部变化的局限。
    3.  **软哈希与对比学习**：为解决二值化不可导问题，训练时采用 `tanh` 激活函数进行**软哈希**，使哈希值在连续空间(0,1)内优化；推理时通过符号函数二值化。训练采用**无监督对比学习**，损失函数在**补丁级**和**全局级**两个层面施加，鼓励同一场景不同时刻（T0, T1）的哈希表示相似，与不同场景的表示相区分。
    4.  **变化检测与定位**：比较两幅图像的**全局哈希码**的汉明距离以快速判断是否发生变化。一旦检测到变化，通过比较对应空间位置**补丁哈希码**的差异，并进行上采样，即可生成变化热力图，实现空间定位。整个过程无需对历史图像进行重复特征提取。
