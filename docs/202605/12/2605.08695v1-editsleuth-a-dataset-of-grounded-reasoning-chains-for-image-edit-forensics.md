## 摘要
AI编辑图像的取证分析不仅需要二元真实与虚假预测：一个有用的系统应该定位编辑、识别其语义类型，并将其决策基于视觉证据。现有的图像取证数据集通常强调检测或定位，而推理监督的视觉语言数据集很少针对图像操纵，并且常常依赖于LLM生成的理由，其忠实性难以验证。我们引入了EditSleuth，一个由现有图像编辑语料库构建的257,725个图像编辑三元组的数据集，用于基于证据的图像编辑取证推理。每个示例包括一个编辑后的图像、其源图像、一个二元编辑掩码、一个12类编辑分类标签、一个难度分数和一个六步推理链。EditSleuth的推理链是从三元组基于的上游工件确定性生成的，每个陈述都与一个特定的可计算证据源相关联。我们的分析表明，一个朴素的四分量难度公式在大小特征之间存在秩-2相关性崩溃；一个简化的三分量公式在Pico-Banana和MagicBrush上显著增加了分数分散度。难度在大多数编辑类别内部也有显著变化，表明分数不是编辑类型的代理。作为一项初步学习研究，我们使用LoRA微调了Qwen2-VL-2B，发现链作为目标的监督在可解析答案中的分类准确性上匹配了仅标签基线，同时还产生了仅标签监督无法产生的基于证据的解释性文本。我们发布了数据集、确定性构建管道和试点训练脚本。

## Abstract
Forensic analysis of AI-edited images requires more than binary real-versus-fake prediction: a useful system should localize the edit, identify its semantic type, and ground its decisions in visual evidence. Existing image-forensics datasets typically emphasize detection or localization, while reasoning-supervised vision-language datasets rarely target image manipulation and often rely on LLM-generated rationales whose faithfulness is difficult to verify. We introduce EditSleuth, a dataset of 257,725 image-edit triplets constructed from existing image-editing corpora for grounded image-edit forensic reasoning. Each example includes an edited image, its source image, a binary edit mask, a 12-class edit taxonomy label, a difficulty score, and a six-step reasoning chain. EditSleuth chains are generated deterministically from triplet-grounded upstream artifacts, with each statement tied to a specific computable source of evidence. Our analysis reveals that a naive four-component difficulty formulation suffers from a rank-2 correlation collapse among magnitude features; a simplified three-component formulation substantially increases score dispersion on both Pico-Banana and MagicBrush. Difficulty also varies meaningfully within most edit categories, indicating that the score is not a proxy for edit type. As an initial learning study, we fine-tune Qwen2-VL-2B with LoRA and find that chain-as-target supervision matches a label-only baseline on classification accuracy among parseable answers, while additionally yielding grounded explanatory prose that label-only supervision cannot produce. We release the dataset, the deterministic construction pipeline, and pilot training scripts.

### 2. 方法论
- **核心思想**：将现有的图像编辑数据集（如Pico-Banana, MagicBrush）中的`(源图像, 编辑后图像, 编辑指令)`三元组，通过一个**确定性的五阶段流水线**，转化为包含**编辑掩码、难度分数、编辑类别标签和六步推理链**的取证监督数据。
- **关键技术与流程**：
    1.  **阶段B：掩码生成**：计算源图像与编辑后图像在L*a*b*颜色空间的距离、结构相似性（1-SSIM）和感知距离（LPIPS）三个差异信号，取元素级最大值组合。通过一个双路径规则（基于均值阈值或Otsu二值化后的面积）判断编辑是`全局`还是`局部`的，并生成二值编辑掩码。
    2.  **阶段C：难度评分**：提出一个三分量难度公式 `D = wS * s_struct + wC * s_compact + wI * s_instr`。
        - `s_struct`：基于SSIM的结构性变化分数（编辑幅度）。
        - `s_compact`：基于掩码面积比和最大连通区域面积的掩码紧凑度分数（空间弥散度）。
        - `s_instr`：基于指令长度、动词数等的指令复杂度分数。
        - 解决了之前四分量公式中多个幅度特征存在秩-2相关性坍塌导致分数方差被压缩的问题。
    3.  **阶段D：类别分类**：定义了12类图像编辑分类学（如物体添加、移除、替换、属性改变、风格迁移等）。对于有标注的数据集（如Pico-Banana）直接映射；对于仅有指令的数据集（如MagicBrush），则使用基于规则的正则表达式分类器。
    4.  **阶段E：推理链组合**：生成由六步组成的结构化推理链。每条陈述都源于上游计算得到的工件：
        - 步骤1：引用编辑指令（来自阶段A）。
        - 步骤2：描述空间定位和掩码面积（来自阶段B）。
        - 步骤3：报告结构性变化和紧凑度分数（来自阶段C）。
        - 步骤4：陈述编辑类别及分类依据（来自阶段D）。
        - 步骤5：提供该编辑类别的**通用取证特征模板**（如物体添加常伴有边界不连续和光影不一致），明确标注为类别先验知识。
        - 步骤6：给出难度等级和分数。
    - **关键特性**：整个推理链的生成是**确定性**和**可审计**的，所有数字和类别声明均由具体计算工件支撑，避免了LLM生成理由的不可靠性。

1.  **难度公式改进有效**：V2三分量公式通过避免幅度特征间的相关性坍塌，在Pico-Banana和MagicBrush数据集上分别将难度分数的标准差提升了**55%**和**94%**，显著增强了分数的区分度。

### 8. 不足与局限
- **链式目标模型的格式遵从性瓶颈**：2B参数的模型在生成结构化、可解析的六步链式输出方面存在困难，导致原始分类准确性低于仅标签模型。这限制了当前模型生成可靠解释文本的能力。
- **掩码质量的残余耦合**：V2难度公式中基于图像的`s_struct`和`s_compact`分量在局部编辑上仍存在中等程度的负相关（r=-0.44），这源于掩码生成算法对细微差异的敏感性不足，可能影响难度评估的精度。
- **数据源与编辑器的单一性**：主要训练数据来自Pico-Banana，其掩码反映的是单一文本条件编辑器的特性。训练出的模型可能对来自其他编辑器的编辑泛化能力不足。
- **可审计性的边界**：推理链的忠实性是相对于上游计算工件（掩码、分数等）而言的，但这些工件本身也是算法计算的结果。缺乏人工标注的审计集来验证这些工件的“地面真实性”。
- **实验的初步性**：微调实验规模较小（20K数据，2B模型），且仅对比了两种训练目标。更大规模、更多模型架构和更全面的下游任务评估有待后续工作。
- **推理链的生成与推理的分离**：当前模型只是学习生成了包含数字字段的链，但并未真正从图像对中计算这些数字。模型推理时生成的数字是其估计值，而非验证过的计算值，这会导致可信度漂移。
