## 摘要
基于示例的图像编辑将由源-目标图像对定义的变换应用于新的查询图像。现有方法依赖于成对-对监督范式，需要两个共享相同编辑语义的图像对来学习目标变换。这一约束使得训练数据难以大规模策划，并限制了跨多种编辑类型的泛化能力。我们提出了Delta-Adapter，一种在单对监督下学习可转移编辑语义的方法，无需文本指导。与直接将示例对暴露给模型不同，我们利用预训练的视觉编码器提取语义差，该语义差编码了两张图像之间的视觉变换。这个语义差通过基于Perceiver的适配器注入预训练的图像编辑模型中。由于目标图像从未直接暴露给模型，它可以作为预测目标，从而在不需额外示例对的情况下实现单对监督。这种表述使我们能够利用现有的大规模编辑数据集进行训练。为了进一步促进忠实的变换转移，我们引入了语义差一致性损失，将生成输出的语义变化与从示例对中提取的真实语义差对齐。大量实验表明，Delta-Adapter在已见编辑任务上比四个强基线方法持续提高了编辑精度和内容一致性，同时在未见编辑任务上也更有效地泛化。代码将在 https://delta-adapter.github.io 公开。

## Abstract
Exemplar-based image editing applies a transformation defined by a source-target image pair to a new query image. Existing methods rely on a pair-of-pairs supervision paradigm, requiring two image pairs sharing the same edit semantics to learn the target transformation. This constraint makes training data difficult to curate at scale and limits generalization across diverse edit types. We propose Delta-Adapter, a method that learns transferable editing semantics under single-pair supervision, requiring no textual guidance. Rather than directly exposing the exemplar pair to the model, we leverage a pre-trained vision encoder to extract a semantic delta that encodes the visual transformation between the two images. This semantic delta is injected into a pre-trained image editing model via a Perceiver-based adapter. Since the target image is never directly visible to the model, it can serve as the prediction target, enabling single-pair supervision without requiring additional exemplar pairs. This formulation allows us to leverage existing large-scale editing datasets for training. To further promote faithful transformation transfer, we introduce a semantic delta consistency loss that aligns the semantic change of the generated output with the ground-truth semantic delta extracted from the exemplar pair. Extensive experiments demonstrate that Delta-Adapter consistently improves both editing accuracy and content consistency over four strong baselines on seen editing tasks, while also generalizing more effectively to unseen editing tasks. Code will be available at https://delta-adapter.github.io.

## 1. 核心问题与整体含义
*   **研究动机与背景**：基于示例的图像编辑旨在将由一个源-目标图像对（示例对）定义的变换，应用到新的查询图像上。现有主流方法依赖“成对-对”（pair-of-pairs）监督范式：模型需要同时看到两个具有相同编辑语义的图像对（如 `{a, a'}` 和 `{b, b'}`），并学习将第一个对的变换转移到第二个对的源图像上，以预测其目标图像 `b'`。
*   **核心问题**：这种监督范式存在根本性限制。首先，训练数据必须成对匹配且语义一致，导致数据难以大规模收集，限制了可学习编辑类型的多样性。其次，模型通常需要文本提示来辅助编辑，增加了用户负担且性能受提示词影响。这限制了模型的泛化能力和实用性。
*   **整体含义**：本文旨在打破这种依赖，探索是否能在 **单对监督**（仅使用一对示例图像）且 **无需文本指导** 的条件下，学习到可迁移的编辑语义，从而实现更可扩展、泛化能力更强的示例编辑。

## 2. 方法论
*   **核心思想**：论文的关键洞察在于改变模型的条件输入方式。现有方法直接以完整的示例对 `{a, a'}` 作为条件，导致目标图像 `a'` 完全暴露，因此必须用另一个对来监督 `b'` 的生成。本文提出 **不直接暴露 `a'`**，而是提取并注入一个表示 `a` 到 `a'` 视觉变换的 **语义差（Semantic Delta）** `Δa→a'`。由于模型从未直接看到 `a'`，`a'` 本身就可以作为重建目标，从而实现了对单个示例对的自我监督。
*   **关键技术细节**：
    1.  **语义差提取与投影**：
        *   使用预训练的 SigLIP 视觉编码器提取源图像和目标图像的逐块特征 `fa`, `fa'`。
        *   对特征进行逐令牌的层归一化后，计算差值 `Δa→a' = LN(fa') - LN(fa)`，以抑制实例间幅值差异，保留方向信息。
        *   引入门控残差投影对差值进行细化：`Δ̃a→a' = Δa→a' + tanh(g) · Linear(Δa→a')`。
    2.  **语义差注入**：
        *   使用 **Perceiver 重采样器**（而非简单的全局池化+MLP）将可变长度的语义差特征序列，转换为固定长度的编辑标记（Edit Tokens）。这保留了空间局部性信息。
        *   采用 **逐令牌投影**，为每个编辑标记学习独立的仿射变换，增强其专业性。
        *   将编辑标记通过 **解耦的交叉注意力** 机制注入到冻结的基于 DiT（Diffusion Transformer）的预训练图像编辑模型（FLUX）的各层中，控制注入强度的标量 `λca` 是可学习的。
    3.  **训练目标**：
        *   主损失为 **流匹配损失（Flow Matching Loss）**，用于在给定源图像 `a` 和语义差 `Δa→a'` 的条件下，重建目标图像 `a'`。
        *   辅助损失为 **语义差一致性损失（Semantic Delta Consistency Loss, Lsdc）**：在训练过程中，用模型预测的噪声潜变量估计出的干净图像，计算其与源图像的“预测语义差”，并将其与真实的语义差进行余弦距离对齐（根据变化幅度加权），确保编辑方向的忠实性。
    4.  **测试时自适应（Test-Time Adaptation）**：
        *   对于具有挑战性的未见任务，可以在推理时对给定的单个示例对进行少量梯度更新（如20步），以更好地捕获特定变换，这是单对监督范式带来的自然优势。
