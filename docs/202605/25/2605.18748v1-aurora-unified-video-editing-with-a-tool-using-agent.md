## 摘要
当前视频编辑模型已趋向统一的条件化设计：单一扩散转换器联合处理文本、源视频和参考图像，且一套权重可涵盖替换、移除、风格迁移和参考驱动插入等多种编辑任务。该设计灵活，但前提是用户已提供适配模型的文本、参考图像以及用于局部编辑的空间定位信息，而实际请求中常缺失这些要素。我们提出Aurora，一种代理式视频编辑框架，将工具增强的视觉语言模型（VLM）代理与统一视频扩散转换器相结合。VLM代理将原始用户请求映射为与转换器条件通道对齐的结构化编辑计划，从而在生成前解析文本和视觉上的欠规范问题。我们通过监督数据训练VLM代理，使其掌握完整编辑规划和参考图像选择能力，并结合偏好对数据优化工具使用与指令优化的鲁棒性。我们引入AgentEdit-Bench基准，用于评估在文本和视觉欠规范条件下代理增强的视频编辑性能。在AgentEdit-Bench和两个现有视频编辑基准上的实验表明，Aurora优于仅依赖指令的基线方法，且VLM代理可迁移至兼容的冻结视频编辑模型。项目主页：https://yeates.github.io/Aurora-Page

## Abstract
Recent video editing models have converged on a unified conditioning design: a single diffusion transformer jointly consumes text, source video, and reference images, and one set of weights covers replacement, removal, style transfer, and reference-driven insertion. The design is flexible, but it assumes that the user already provides model-ready text, reference images, and spatial grounding for local edits, which real requests often omit. We present Aurora, an agentic video editing framework that pairs a tool-augmented vision-language model (VLM) agent with a unified video diffusion transformer. The VLM agent maps a raw user request to a structured edit plan aligned with the transformer's conditioning channels, thereby resolving textual and visual underspecification before generation. We train the VLM agent with supervised data for complete edit planning and reference-image selection, together with preference pairs for robust tool use and instruction refinement. We introduce AgentEdit-Bench to evaluate agent-enhanced video editing under textual and visual underspecification. Experiments on AgentEdit-Bench and two existing video editing benchmarks show that Aurora improves over instruction-only baselines and that the VLM agent transfers to compatible frozen video editing models. *   **核心问题**：这种设计虽然灵活，但其隐含前提是用户必须提供“模型就绪”的、完整的输入条件。然而，**现实中的用户请求往往是“欠规范”的**，主要体现在两个方面：
    1.  **文本欠规范**：编辑目标描述不明确或间接（例如，“把蓝色物品改成跑得更快的车辆”）。
    2.  **视觉欠规范**：用户指定了编辑目标或区域，但未提供必要的视觉输入（例如，要求替换为特定品牌，但未提供该品牌的参考图像）。
*   **研究意义**：论文将此问题定义为“条件构建问题”。现有模型定义了所需的条件输入（文本、参考图像、掩码），但未能解决如何从模糊、不完整的用户原始请求中推断并构建出这些条件。Aurora 旨在填补这一空白，将“条件构建”与“视频生成”解耦，提升统一视频编辑框架对真实用户请求的鲁棒性和实用性。

## 2. 方法论：核心思想、关键技术细节
Aurora 框架的核心是将一个**工具增强的视觉语言模型（VLM）代理**与一个**统一的视频扩散转换器（DiT）** 相结合。
*   **核心思想**：将视频编辑流程分为两阶段：
    1.  **代理阶段（条件构建）**：VLM 代理解析原始用户请求，通过调用外部工具获取缺失信息，并生成一个结构化的“编辑计划”。
    2.  **生成阶段（视频编辑）**：统一的视频 DiT 接收由代理构建的完整条件，生成编辑后的视频。
*   **关键技术细节**：
    *   **VLM 代理**：
        *   **模型**：基于 Qwen3-VL-8B-Instruct 进行 LoRA 微调。
        *   **输出**：一个四字段的 JSON 编辑计划 `(y', c, q, m)`，分别代表重写后的指令、任务标签、图像搜索查询（可选）、掩码短语（可选）。
        *   **工具调用**：根据 `q` 和 `m` 字段，代理调用两个外部工具：
            *   `T_search`：通过网络图像检索（Serper API）获取参考图像。
            *   `T_mask`：结合 GroundingDINO 和 SAM 进行定位和分割，生成带掩码的图像。
        *   **训练**：采用**监督微调（SFT）** 进行完整编辑规划和参考图像选择训练，并使用**直接偏好优化（DPO）** 进行偏好对齐，以优化边界情况（如错误触发工具、约束丢失等）。
    *   **统一视频 DiT**：
        *   **模型基础**：基于 Wan2.2-TI2V-5B 构建。
        *   **双路径条件输入**：
            1.  **多模态上下文路径**：使用一个冻结的 Qwen3.5-4B 编码器，将重写后的指令、源视频帧和参考图像编码为统一的上下文向量，输入 DiT 的交叉注意力层。
            2.  **潜在令牌序列路径**：将源视频、参考图像的 VAE 编码（通过一个**零时间步调制**机制）与噪声视频令牌在序列维度上拼接，输入 DiT 的自注意力层。此设计使条件令牌在去噪过程中保持稳定。
        *   **训练**：使用**流匹配（Flow Matching）** 目标进行训练，并包含提示词丢弃和视觉丢弃以支持推理时的引导。

## 8. 不足与局限
*   **训练与优化局限**：VLM代理仅使用了离线DPO进行偏好对齐，未采用更先进的在线强化学习（如GRPO），因为计算成本过高。

*   **应用风险**：与所有视频编辑工具类似，Aurora可能被用于非合意的身份篡改。此外，图像检索工具可能引入版权和肖像权风险。
