## 摘要
尽管扩散和流模型具有生成能力，真实图像编辑仍然受到语义可编辑性和结构保真度之间持久权衡的约束。我们将这一限制的主要原因追溯到现有范式中编辑进度与模型尺度的隐式耦合。在这种耦合下，更强的编辑通常需要访问更嘈杂的状态，这在语义变化被良好定位之前，将计算花费在不稳定布局上。我们引入NaviEdit，一个无需训练的推理时控制器，通过严格的自洽契约将编辑进度与模型尺度遍历解耦。NaviEdit在展开级别操作，并保持底层预训练模型不变。它将尺度视为控制输入，并将固定的步骤预算重新分配到语义响应性的中间尺度，而不是破坏性的高噪声区域。实验显示，在兼容的编辑器和流骨干网络上，平均增益为正，支持解耦作为可移植的推理时控制原则。

## Abstract
Despite the generative capabilities of diffusion and flow models, real-image editing remains constrained by a persistent trade-off between semantic editability and structural fidelity. We trace a primary cause of this limitation to the implicit coupling of edit progress with model scale in existing paradigms. Under this coupling, stronger edits typically require visiting noisier states, which spends computation on destabilizing layout before the semantic change is well localized. We introduce NaviEdit, a training-free inference-time controller that decouples edit progress from model scale traversal through a strict self-consistency contract. NaviEdit operates at the rollout level and leaves the underlying pretrained model unchanged. It treats scale as a control input and reallocates a fixed step budget toward semantically responsive intermediate scales instead of destructive high-noise regimes. Experiments show positive average gains across compatible editors and flow backbones, supporting decoupling as a portable inference-time control principle.

- **问题根源**：论文指出，现有大多数无训练编辑方法（如SDEdit, FlowEdit）存在一个隐式设计缺陷——将**编辑进度**（已完成的语义改变量）与**模型尺度**（扩散/流模型的噪声水平坐标）耦合。更强的编辑意味着向更高噪声的尺度扩展，导致计算资源浪费在不稳定的布局上。
- **整体含义**：本文旨在从根本上解耦这两个概念，提出一种通用的推理时控制原则，以在固定计算预算内，更好地平衡语义可编辑性与结构保真度。

## 2. 提出的方法论
- **核心思想**：提出 **NaviEdit**，一个**无需训练、即插即用**的推理时控制器。其核心是**解耦**：将显式的**编辑进度轴**与模型内部的**尺度轴**分离，并通过严格的自洽契约保证离散化步骤的稳定性。
- **关键技术细节**：
    1.  **尺度作为控制输入**：将模型的噪声/时间坐标（尺度）视为一个导航空间，而非进度时钟。
    2.  **定义有效尺度窗口 (U_eff)**：通过实证诊断发现，中间尺度区域是“结构甜点”（语义响应性强且空间锚定），而高噪声尾部（高尺度）风险高（泄漏压力大）。NaviEdit将计算集中在这个有效窗口内。
    3.  **固定预算下的密度优化**：在固定模型调用次数（K步）预算下，通过优化计算在尺度轴上的**密度分配**（在有效窗口内更密集地采样），而非盲目**扩展范围**（进入高风险区域），来提升质量。
    4.  **自洽离散化契约**：确保每个步骤在构建锚点、查询模型和应用更新时，使用**相同的尺度坐标**。违反此契约会引入系统性偏差，导致漂移。
    5.  **可选内部门控**：可从模型内部表征中提取可行区域掩码（无需额外外部掩码），将微分场投影到目标区域，进一步抑制非编辑区域的改动。
- **算法流程**：控制器接收源图像、源/目标提示词、预训练模型和固定步数K。它维护一个独立的进度坐标p，在每个步骤k中：1) 通过p映射到当前尺度u_k；2) 构建共位锚点；3) 查询模型得到微分场；4) （可选）应用内部门控；5) 使用自洽的更新规则推进潜变量；6) 根据（可选的）在线风险信号调整下一进度步长。

## 6. 主要结论与发现
- **核心结论**：将**编辑进度**与**模型尺度**解耦，是一种通用且有效的推理时控制原则。在固定计算预算下，**密度优化**（在有效尺度窗口内集中计算）优于**范围扩展**（访问更高噪声状态）。
- **关键发现**：
    1.  实证发现模型尺度轴上存在“可编辑信息谱”，中间尺度是最优窗口。
    2.  NaviEdit控制器在FlowEdit实例化（Navi-FlowEdit + gate）上显著提升了所有PIE-Bench指标。
    3.  该原则可正向迁移至其他兼容编辑器（InfEdit, FlowAlign）和不同的流模型骨干，证明了其可移植性。
    4.  简单增加分类器自由引导强度无法复现解耦带来的改进。
