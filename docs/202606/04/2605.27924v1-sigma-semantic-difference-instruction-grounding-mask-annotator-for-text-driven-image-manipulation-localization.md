## 摘要
文本驱动图像编辑已迅速发展，但可靠地定位这些操作需要在大型像素标注数据集上训练的图像操作定位（IML）模型，并且目前仍没有低成本的方法来大规模获取此类训练数据。我们观察到这些数据实际上已经存在：公开的编辑数据集包含数百万个结构上与IML训练样本相同的（原始，编辑）对，仅缺少像素级掩码。自动恢复这些掩码并非易事：像素差异被扩散引起的跨所有像素扰动所淹没，而仅基于指令的基础只能定位提示描述的内容，忽略了编辑器无意中的副作用。我们提出了SIGMA（语义差异指令基础掩码标注器），它在视觉基础骨干中执行语义特征差异，并通过双向跨模态细化将指令派生的空间先验注入到这个视觉流中，当编辑器忠实实现用户意图时，放大意图编辑区域的差异信号。SIGMA在两个互补阶段进行训练：阶段I在修复掩码上进行监督；阶段II通过VAE往返噪声校准、EMA自训练和编辑噪声解耦损失来弥合扩散域偏移。SIGMA在五个基准测试中优于现有的自动掩码生成器（F1提升+12.20%，IoU提升+11.16%）。当应用于公开编辑语料库时，它产生了一个约110万个IML训练集，在五个数据集上将六个不同检测器的F1提升了+18.34%，将之前未使用的编辑数据转变为IML的模型无关监督资源。一旦论文被接受，我们将发布完整的代码库。

## Abstract
Text-driven image editing has advanced rapidly, but reliably localizing these manipulations requires image manipulation localization (IML) models trained on large pixel-annotated datasets, and there is still no low-cost way to obtain such training data at scale. We observe that these data already exist in disguise: public editing datasets contain millions of structurally identical (original, edited) pairs to IML training samples, lacking only pixel-level masks. Recovering these masks automatically is non-trivial: pixel differencing is overwhelmed by diffusion-induced perturbations across all pixels, and instruction-only grounding localizes only what the prompt describes, missing unintended editor side-effects. We propose SIGMA (Semantic-difference Instruction-Grounding Mask Annotator), which performs semantic-feature differencing in a vision foundation backbone and injects an instruction-derived spatial prior into this visual stream via bidirectional cross-modal refinement, amplifying the difference signal at intended-edit regions when the editor faithfully realizes user intent. SIGMA is trained in two complementary stages: Stage I supervises on inpainting masks; Stage II closes the diffusion-domain shift via VAE-roundtrip noise calibration, EMA self-training, and an edit-noise disentanglement loss. SIGMA outperforms existing automatic mask generators on five benchmarks (+12.20% F1, +11.16% IoU). When applied to public editing corpora, it produces a ~1.1M IML training set that improves six diverse detectors by +18.34% F1 across five datasets, turning previously unused editing data into a model-agnostic supervisory resource for IML. We'll release the full codebase as soon as the paper is accepted.

## 1. 论文的核心问题与整体含义（研究动机和背景）
*   **研究动机**：文本驱动图像编辑技术快速发展，产生了大量逼真的AI编辑图像。为了应对其带来的伪造风险，需要训练鲁棒的图像操作定位（IML）模型来精确检测编辑区域。训练这类模型依赖大规模、像素级标注的数据集。
*   **核心问题**：存在显著的“数据规模鸿沟”：公开的文本驱动图像编辑数据集（如ByteMorph, AnyEdit）规模巨大（百万级），但只包含（原图，编辑图，指令）三元组，缺乏像素级掩码；而现有的IML数据集虽有掩码，但规模较小且编辑类型有限。**低成本、自动地将这些海量编辑数据转换为带像素级掩码的IML训练数据，是本文要解决的核心问题。**
*   **现有方法的不足**：两种直观的自动掩码生成方法均有缺陷：
    1.  **像素差分法**：在扩散模型编辑下，所有像素都会经历VAE编解码和去噪扰动，导致基于像素值差异的方法被噪声淹没，无法分离真正的语义编辑和重建噪声。
    2.  **纯指令定位法**：仅根据文本指令定位，但无法验证编辑器是否忠实执行了指令，也无法捕获编辑过程中引入的非预期副作用。
*   **核心洞察**：作者认为上述两种方法本质上是**互补**而非替代的。像素差分观察“什么变了”，指令定位理解“意图在哪变”。因此，需要一种方法将两者结合。

## 2. 论文提出的方法论
*   **核心思想**：提出SIGMA框架，通过**语义级特征差分**和**指令引导空间先验**的双向融合，来精确生成文本驱动图像编辑的像素级掩码。
*   **关键技术细节**：
    1.  **语义差异分支**：
        *   使用冻结的DINOv2视觉基础模型作为共享编码器，提取原图和编辑图在多尺度（浅层纹理、深层语义）上的特征。
        *   计算L2归一化后特征间的绝对差异和余弦相似度，融合并投影得到多尺度差分特征。
        *   通过**差异精炼模块**进行跨尺度注意力增强，抑制噪声，突出编辑信号。
    2.  **指令基础分支**：
        *   **语义转换解析器**：使用Qwen2.5-0.5B语言模型，从编辑指令中解析出结构化三元组（原概念，编辑概念，操作类型）。
        *   **SAM引导的注意力构建**：利用GroundingDINO+SAM，分别将原概念和编辑概念定位到对应的图像上，生成概念相关的注意力图。
        *   **动作条件空间融合**：根据操作类型（添加、移除、替换等），用规则（如乘积、选择）融合两个注意力图，生成意图空间先验图。
    3.  **双向跨模态细化**：
        *   将语义差异分支的视觉证据与指令基础分支的意图先验进行迭代交叉注意力融合。
        *   关键设计：首先，视觉流吸收先验以增强相关信号；然后，意图先验流回过来被更新的视觉证据所锚定和修正，实现双向验证与精炼。
    4.  **掩码解码器**：融合多尺度精炼后的差分特征与共识特征，通过卷积网络预测最终的二值掩码。
*   **训练策略（两阶段）**：
    *   **阶段I**：在带有精确掩码的图像修复数据上进行监督训练，学习定位语义变化的强先验。
    *   **阶段II**：在无标签的文本驱动编辑数据上进行自监督域适应。
        *   **VAE往返噪声校准**：通过向原图添加轻微噪声后重构，生成一个语义不变的“负样本”，监督模型输出全零掩码，以适应扩散噪声。
        *   **EMA自训练**：使用教师模型生成高置信度伪标签，指导学生模型学习。
        *   **编辑-噪声解耦损失**：在预测的编辑区域内，对比真实编辑对和噪声对的特征，将其推入可分离的子空间，迫使模型关注语义变化而非噪声。
