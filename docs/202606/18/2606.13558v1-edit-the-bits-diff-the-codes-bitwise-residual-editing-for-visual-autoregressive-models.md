## 摘要
使用视觉自回归（VAR）生成器进行文本引导图像编辑，需要同时控制模型采样的内容以及采样的变更被写回图像代码的位置。现有的VAR编辑器主要在token流、特征或扁平的下一token对数几率上进行操作，未能充分利用比特级残差VAR模型的两个原生结构：逐比特伯努利预测头以及用于组装图像的加性多尺度残差码场。我们提出了BitResEdit，这是一种面向比特级残差VAR生成器（如Infinity）的免训练编辑器。BitEdit通过在共享编辑前缀上计算的源-目标对比度，倾斜后CFG的逐比特对数几率来进行源-负向引导，然后将每次更新投影到围绕干净CFG采样器的闭式伯努利-KL置信域中。ResEdit将采样的比特转换为逐尺度连续码残差，使用定位掩码对其进行门控，并通过生成器原生的尺度求和机制重新注入。两者共同耦合了决策时比特引导与组合时代码合成，使得被掩码的潜在特征通过代码算术被精确保留，而局部的、尺度感知的编辑则被应用于目标区域内。在使用Infinity-2B的PIE-Bench基准测试中，BitResEdit在相同骨干的VAR编辑器中实现了最强的文本对齐能力，在编辑区域的CLIP分数上比先前最强的编辑器提高了+1.07，同时背景保持能力与其相当。消融实验表明，BitEdit和ResEdit在目标对齐和背景保持方面扮演着互补的角色。

## Abstract
Text-guided image editing with visual autoregressive (VAR) generators requires controlling both what the model samples and where the sampled change is written back into the image code. Existing VAR editors mainly operate on token streams, features, or flat next-token logits, leaving two native structures of bitwise-residual VAR models underused: the per-bit Bernoulli prediction head and the additive multi-scale residual code field from which the image is assembled. We propose BitResEdit, a training-free editor for bitwise-residual VAR generators such as Infinity. BitEdit performs source-negative guidance by tilting the post-CFG per-bit log-odds along a source--target contrast computed on a shared edited prefix, then projects each update into a closed-form Bernoulli-KL trust region around the clean CFG sampler. ResEdit converts the sampled bits into per-scale continuous-code residuals, gates them with a localization mask, and re-injects them through the generator's native sum-of-scales. Together they couple decision-time bit guidance with combination-time code composition, so masked-out latent features are preserved exactly by code arithmetic while localized, scale-aware edits are applied inside the target region. On PIE-Bench with Infinity-2B, BitResEdit attains the strongest text alignment among same-backbone VAR editors, improving CLIP on the edited region by +1.07 over the strongest prior editor while keeping background preservation competitive with it. Ablations show BitEdit and ResEdit play complementary roles in target alignment and background preservation.

# 论文《Edit the Bits, Diff the Codes: Bitwise Residual Editing for Visual Autoregressive Models》总结

## 1. 核心问题与整体含义
- **研究背景**：文本引导图像编辑要求精确修改图像指定区域，同时保持无关内容。视觉自回归（VAR）模型（如Infinity）通过多尺度离散代码生成图像，比扩散模型延迟更低，但其编辑机制不同。
- **现有问题**：当前VAR编辑器主要操作于token流、特征或整体logits层面，未能充分利用比特级残差VAR模型的两个原生结构：**逐比特伯努利预测头**和**加性多尺度残差码场**。
- **研究动机**：由于VAR模型在不同尺度间存在决策依赖，且编辑需要决定“改什么”和“写在哪”，因此需要一种方法，直接在模型最底层的比特分布和组合算术层面进行精准干预，而非将扩散模型方法作为黑盒迁移。

## 2. 方法论
- **核心思想**：提出 **BitResEdit**，一个**免训练**的编辑器，将编辑过程解耦为**决策时**的比特引导和**组合时**的代码合成，并充分利用VAR模型原生代数结构。
- **关键技术细节**：
    1.  **BitEdit（决策时，比特引导）**：
        -   **源-负向引导**：在后CFG（Classifier-Free Guidance）的逐比特对数几率（log-odds）空间，沿“源提示”与“目标提示”的对比方向进行倾斜。
        -  **伯努利-KL置信域投影**：将倾斜后的结果投影到一个围绕原始干净采样器的伯努利分布KL散度球内，确保引导后分布不偏离模型原有分布太远。
        -   **引导强度调度**：采用线性退火策略，引导强度从粗尺度到细尺度逐渐减弱，聚焦于高层语义改变。
    2.  **ResEdit（组合时，代码合成）**：
        -   **残差生成与门控**：将BitEdit采样后的比特转换为连续码残差，并用一个经过处理的**空间定位掩码**进行门控。
        -   **残差注入**：将门控后的残差通过模型原生的**多尺度码场求和**机制注入，实现编辑。在掩码外区域，残差为零，从而精确保留背景潜在特征。
- **算法流程**：
    -   首先运行一次源图像，缓存其各尺度的源代码和处理后的编辑掩码。
    -   对每个生成尺度（从粗到细），依次执行：三分支前向计算（目标、无条件、源提示）→ CFG组合 → BitEdit引导与采样 → ResEdit生成门控残差并更新累积潜在码。

- **评估指标**：
    -   **背景保持**：PSNR、LPIPS、MSE、SSIM（评估未编辑区域与原图的相似度）。
    -   **文本对齐**：CLIP图像-文本相似度（评估整体图像和编辑区域与提示的匹配度）。
- **对比方法**：
    -   **VAR编辑器**：AREdit、VAREdit-8B、EditInfinity。
    -   **扩散/流匹配编辑器**：FlowChef、VAGS、RewardFlow（20B参数）等。

## 4. 资源与算力
- **硬件环境**：所有延迟测试在 **NVIDIA A100-80GB GPU** 上进行。

## 6. 主要结论与发现
-   BitResEdit在**相同骨干的VAR编辑器**中，在文本对齐（CLIP分数）上取得**最优表现**，编辑区域CLIP比最强先前编辑器提升+1.07，同时背景保持有竞争力。
-   **BitEdit与ResEdit功能互补**：BitEdit主要驱动目标对齐，ResEdit主要保障背景保持。两者耦合使用效果最佳。
-   **方法高效**：无需训练或微调，编辑速度快（约10秒/图）。
-   **局限**：在“物体删除”任务上表现不佳，因为目标提示缺乏正向生成指导，模型倾向于重新渲染或产生不连贯内容。

## 7. 优点
-   **方法设计优雅**：深刻理解并充分利用了比特级残差VAR模型的**原生代数结构**（逐比特伯努利分布、多尺度码场求和），设计精准。
-   **两阶段解耦**：将“引导采样”与“写入代码”解耦，逻辑清晰，各组件作用明确。
-   **训练免费**：无需任何模型微调，开箱即用，实用性强。
-   **理论保障**：通过KL置信域投影，在数学上约束了编辑过程不偏离模型原有分布，增强了稳定性。
-   **实验全面**：系统性的消融实验验证了每一个设计选择的有效性。

## 8. 不足与局限
-   **任务局限**：对**物体删除**等“减法”编辑任务效果差，因为缺乏正向生成目标。
-   **掩码依赖性强**：编辑质量严重依赖提供的定位掩码的准确性。使用自动掩码（如GroundingDINO+SAM）或边界框会导致性能显著下降。
-   **计算开销**：BitEdit的**三分支前向**（目标、无条件、源提示）增加了计算量，虽然与同类方法相当，但比单分支方法更耗时。
-   **编辑能力范围**：依赖于VAR模型本身的生成能力和先验。对于模型训练数据分布外或极其复杂的编辑指令，效果可能受限。
-   **背景保持的边界效应**：虽然潜在码在掩码外被精确保留，但经VAE解码器后，可能因感受野或掩码边缘模糊化而引入微小的像素级偏差。
