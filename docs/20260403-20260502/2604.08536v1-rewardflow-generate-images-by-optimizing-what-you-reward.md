## 摘要
我们介绍RewardFlow，一个无逆框架，通过多奖励朗之万动力学在推理时引导预训练的扩散和流匹配模型。RewardFlow统一了用于语义对齐、感知保真度、局部定位、物体一致性和人类偏好的互补可微奖励，并进一步引入了一个基于VQA的可微奖励，通过语言-视觉推理提供细粒度的语义监督。为了协调这些异构目标，我们设计了一个提示感知的自适应策略，从指令中提取语义原语，推断编辑意图，并在采样过程中动态调整奖励权重和步长。在多个图像编辑和组合生成基准测试中，RewardFlow实现了最先进的编辑保真度和组合对齐。

## Abstract
We introduce RewardFlow, an inversion-free framework that steers pretrained diffusion and flow-matching models at inference time through multi-reward Langevin dynamics. RewardFlow unifies complementary differentiable rewards for semantic alignment, perceptual fidelity, localized grounding, object consistency, and human preference, and further introduces a differentiable VQA-based reward that provides fine-grained semantic supervision through language-vision reasoning. To coordinate these heterogeneous objectives, we design a prompt-aware adaptive policy that extracts semantic primitives from the instruction, infers edit intent, and dynamically modulates reward weights and step sizes throughout sampling. Across several image editing and compositional generation benchmarks, RewardFlow delivers state-of-the-art edit fidelity and compositional alignment.

## 2. 方法论
*   **核心思想**：提出 **RewardFlow** 框架，将图像生成/编辑过程视为在推理时对一组**可微奖励**进行优化的朗之万动力学采样过程。通过融合多种互补的奖励信号，并利用一个**提示感知的自适应策略**动态调整优化方向与强度，从而引导预训练的流匹配模型生成符合指令的图像。
*   **关键技术细节**：
    1.  **多奖励朗之万动力学**：在每个去噪步骤，将中间解码图像作为优化变量，计算一组可微奖励的梯度，并通过解码器和去噪器的雅可比矩阵将梯度映射回潜空间，形成奖励引导的漂移项，增强原始的流匹配动力学。
    2.  **分层可微奖励**：设计了一套从粗到细的奖励体系：
        *   **语义原语级奖励**：针对从指令中解析出的每个原子操作（如“移除帽子”）单独计算，包括**全局/感知对齐奖励**、**区域定位奖励**和**物体一致性奖励**（基于SAM2）。
        *   **全局提示级奖励**：包括**人类偏好奖励**和创新的**可微VQA奖励**，后者通过语言-视觉问答提供细粒度语义监督。
    3.  **提示感知自适应策略**：作为核心控制器，该策略在采样前利用LLM解析指令，提取**语义原语**并推断编辑意图（添加/移除/风格化）。在采样过程中，它动态调整：
        *   **奖励权重**：基于意图先验、奖励反馈和噪声水平调度。
        *   **物体方向**：根据意图乘以+1或-1，控制物体出现或消失。
        *   **奖励感知步长**：根据当前总奖励值自适应调整，奖励高时小步精炼，奖励低时大步探索。
    4.  **身份保持KL系绳**：引入一个正则项，将预测的干净潜变量拉向原始图像的潜表示，以防止奖励优化导致的布局失真和身份漂移。
*   **算法流程**：简要概括为：编码输入图像 -> 解析指令得到语义原语 -> 初始化带噪潜变量 -> 循环执行（去噪得到中间图像 -> 计算所有奖励 -> 自适应策略融合奖励并调整步长 -> 计算梯度更新潜变量）-> 解码最终图像。
