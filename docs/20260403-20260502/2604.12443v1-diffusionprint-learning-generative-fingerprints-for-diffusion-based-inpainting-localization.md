## 摘要
现代基于扩散的修复模型对图像伪造定位（IFL）提出了重大挑战，因为它们的完整重建流程通过潜在解码器重建整个图像，破坏了现有取证方法所依赖的相机级噪声模式。我们提出DiffusionPrint，一个块级对比学习框架，学习对潜在解码器引入的频谱失真鲁棒的取证信号。它利用同一模型生成的修复区域共享一致的生成指纹这一事实，将其用作自监督信号。DiffusionPrint通过MoCo风格目标训练卷积骨干网络，结合跨类别硬负样本挖掘和生成器感知分类头，生成取证特征图，作为基于融合的IFL框架中高度判别性的次要模态。集成到TruFor、MMFusion和轻量级融合基线中，DiffusionPrint在多个生成模型上一致地提高了定位性能，在微调期间未见过的掩码类型上提升高达+28%，并确认泛化到未见过的生成架构。代码可在https://github.com/mever-team/diffusionprint获取。

## Abstract
Modern diffusion-based inpainting models pose significant challenges for image forgery localization (IFL), as their full regeneration pipelines reconstruct the entire image via a latent decoder, disrupting the camera-level noise patterns that existing forensic methods rely on. We propose DiffusionPrint, a patch-level contrastive learning framework that learns a forensic signal robust to the spectral distortions introduced by latent decoding. It exploits the fact that inpainted regions generated by the same model share a consistent generative fingerprint, using this as a self-supervisory signal. DiffusionPrint trains a convolutional backbone via a MoCo-style objective with cross-category hard negative mining and a generator-aware classification head, producing a forensic feature map that serves as a highly discriminative secondary modality in fusion-based IFL frameworks. Integrated into TruFor, MMFusion, and a lightweight fusion baseline, DiffusionPrint consistently improves localization across multiple generative models, with gains of up to +28% on mask types unseen during fine-tuning and confirmed generalization to unseen generative architectures. Code is available at https://github.com/mever-team/diffusionprint

## 1. 核心问题与整体含义
*   **研究背景与动机**：现代基于扩散模型的文本引导图像修复（Inpainting）技术，能够生成高度逼真的编辑结果，对图像取证构成严峻挑战。与传统“拼接”仅替换局部区域不同，扩散模型的修复流程是“全再生”的：整个图像（包括未编辑区域）都会经过潜在空间的编码-解码过程。这一过程会破坏图像固有的、用于取证分析的相机传感器噪声模式（如PRNU），导致依赖此类低层信号的传统图像伪造定位（IFL）方法失效。
*   **核心问题**：如何为这种“全再生”修复场景设计一种新的、鲁棒的取证信号，以准确定位被修复的区域？该信号需要满足两个关键特性：1）对未编辑区域因潜在解码引入的全局频谱失真保持不变性；2）对编辑区域由生成模型引入的特定“指纹”保持敏感性。

## 2. 方法论
*   **核心思想**：提出 **DiffusionPrint**，一个基于块级对比学习的框架。其核心洞察是：由同一生成模型修复的图像区域会共享一个一致的“生成指纹”。DiffusionPrint旨在学习一个编码器，将图像块映射到一个特征空间，使得该指纹成为区分修复块与真实块的判别性信号。
*   **关键技术细节**：
    *   **正样本对构建**：设计了非对称的正样本对策略。
        *   **对于生成图像**：取一张由生成模型 `g_i` 生成的图像，再用 `g_i` 的修复版本对其进行修复。将修复前后的**同一空间位置**的图像块作为正样本对。这迫使编码器学习该生成模型固有的指纹。
        *   **对于真实图像**：取一张真实图像，分别用多个生成模型对其进行修复。将原始真实块与其所有潜在重建后的对应块作为正样本对。这迫使编码器学习对潜在重建失真的不变性。
    *   **负样本挖掘**：采用 **MoCo** 风格的对比学习框架，使用动量编码器和队列存储负样本。关键创新是**跨类别硬负样本挖掘**：对于每个锚点（如修复块），从队列中选取与其最相似的**真实块**作为负样本（反之亦然）。这迫使模型关注最具挑战性的、在视觉上相似但类别不同的样本，从而学习更精细的判别边界。
    *   **训练目标**：使用 **InfoNCE** 损失进行对比学习。同时，引入一个可选的**生成器感知分类头**（4类：真实、SD2.1、SDXL、Flux），与对比损失联合优化，以显式鼓励模型学习生成器特定的指纹。
