## 摘要
大型扩散变换器（DiTs）能很好地遵循全局编辑指令，但总是将局部编辑泄漏到不相关区域，因为联合注意力架构没有提供明确的通道来告诉网络在哪里应用编辑。我们引入REDEdit，一个共同训练的、指令和区域感知的适配器框架，它将冻结的DiT改装成一个精确的局部编辑器，而不修改其骨干权重。在每个变换器块中，一个轻量级的块适配器注入一个结构化条件流，将编辑什么（指令语义）与在哪里编辑（空间掩码）分离；一个学习的空间门将适配器信号选择性地路由到编辑区域，同时保持图像的其余部分与源图像几乎相同；一个区域感知损失将训练目标聚焦在变化的像素上。因为这些组件使骨干的内部表示端到端地掩码感知，一个与编辑器共同训练的薄掩码预测器头可以直接从指令和源图像中定位编辑区域，从而在部署时消除任何用户掩码需求。我们在两个互补的基准上进行评估：MagicBrush（配对的真实目标）用于测量像素级保留和编辑准确性，以及Emu-Edit Test（无真实图像，9种多样编辑类别）用于压力测试指令遵循和跨编辑类型的泛化。在两者上，REDEdit都达到了最先进的结果，同时优于无掩码和神谕掩码基线。一个七变体消融干净地隔离了每个组件的贡献。

## Abstract
Large diffusion transformers (DiTs) follow global editing instructions well but consistently leak local edits into unrelated regions, because joint-attention architectures offer no explicit channel telling the network where to apply the edit. We introduce REDEdit, a co-trained, instruction- and region-aware adapter framework that retrofits a frozen DiT into a precise local editor without modifying its backbone weights. A lightweight Block Adapter at every transformer block injects a structured condition stream that factorizes what to edit (instruction semantics) from where to edit (spatial mask); a learned SpatialGate routes the adapter signal selectively into the edit region while keeping the rest of the image near-identical to the source; and a Region-Aware Loss focuses the training objective on the changing pixels. Because these components make the backbone's internal representation mask-aware end-to-end, a thin MaskPredictor head trained jointly with the editor can ground the edit region directly from the instruction and source image eliminating any user-mask requirement at deployment. We evaluate on two complementary benchmarks: MagicBrush (paired ground-truth targets) to measure pixel-level preservation and edit accuracy, and Emu-Edit Test (no ground-truth images, 9 diverse edit categories) to stress-test instruction following and generalization across edit types. On both, REDEdit achieves state-of-the-art results, simultaneously outperforming mask-free and oracle-mask baselines. A seven-variant ablation cleanly isolates the contribution of each component.

## 1. 核心问题与整体含义
*   **研究动机**：当前主流的大型扩散变换器（DiTs）在遵循文本指令进行图像编辑时，虽然能很好地处理全局编辑，但在执行**局部编辑**（如“只把杯子变成红色”）时，编辑效果会不可避免地**泄漏**到图像的其他无关区域。这是因为其核心的联合注意力架构缺乏一个明确的通道来告知网络编辑应施加在何处。
*   **背景与含义**：现有的解决方案要么依赖用户手动提供精确的编辑区域掩码（不实用），要么通过分割模型生成掩码（增加延迟和误差）。本文旨在解决这一根本性问题，使大型DiT能够**精确、自动地**执行局部编辑，无需用户干预，这对电商、广告设计等实际应用至关重要。

## 2. 方法论
*   **核心思想**：在不修改冻结的大型DiT骨干网络权重的前提下，通过注入一个**协同训练的、指令与区域感知的适配器框架**，为其显式地增加“编辑什么”（语义）和“在哪里编辑”（空间）两个通道，从而将通用编辑器改造为精确的局部编辑器。
*   **关键技术细节**：
    1.  **Block Adapter**：在DiT的每个Transformer块中插入一个轻量级的交叉注意力适配器。它接收一个结构化的条件流，并通过门控残差将信号注入骨干网络。
    2.  **Condition Encoder**：将编辑指令和空间掩码信息分离并融合。
        *   **空间编码器**：将二值编辑掩码下采样并转换为离散的“编辑/保留”令牌。
        *   **指令编码器**：使用Perceiver投影器压缩多模态大语言模型（Qwen2.5-VL）的隐藏状态，生成固定数量的语义令牌。
        *   **融合**：通过一个小型Transformer融合空间和语义令牌，形成统一的条件流。
    3.  **SpatialGate**：基于掩码生成一个**可学习的、逐令牌的软门控信号**。它选择性地将适配器信号路由到编辑区域（门控值接近1），同时保持图像其余部分几乎不变（门控值接近0），避免了硬边界产生的接缝伪影。
    4.  **Region-Aware Loss**：重新加权标准的速度预测损失，通过一个系数α（论文中设为2）**聚焦于变化像素**的梯度，防止模型被大量未变化的“简单”像素主导。
    5.  **MaskPredictor**：一个轻量级的头部，与编辑器**联合训练**。它直接从指令和源图像中预测编辑区域掩码，从而在**推理时完全取代用户提供的掩码**。训练采用**解耦监督**策略，避免了编辑路径和掩码预测相互干扰的失败模式。

## 6. 主要结论与发现
*   **主要结论**：REDEdit框架成功地将一个冻结的大型DiT改装成了精确的局部编辑器。它在MagicBrush和Emu-Edit Test两个基准上均达到了**最先进（SOTA）** 的结果，同时优于无掩码和神谕掩码基线。
*   **关键发现**：
    *   **组件有效性**：消融实验证明，Block Adapter贡献了最大的性能提升（占总差距的84%），其他组件（Region-Aware Loss, SpatialGate, MaskPredictor）进一步带来互补性增益。
    *   **掩码预测器**：联合训练的MaskPredictor能够准确地从指令和源图像中定位编辑区域，使系统在推理时无需任何用户掩码。
    *   **权衡**：作为精确局部编辑器，REDEdit在保持未编辑区域像素级相似性（高CLIP-I/DINO）的同时，其全局文本-图像对齐度（CLIP-T）会略有下降，这是符合预期的设计权衡。

## 7. 优点
*   **方法设计巧妙**：通过适配器注入显式分离“what”和“where”信息，直击联合注意力架构的缺陷，设计思路清晰有效。
*   **参数高效**：仅需微调约25%的参数，且骨干网络完全冻结，保留了其强大的生成先验。
*   **端到端无掩码推理**：MaskPredictor的引入使系统在部署时完全自动化，实用性极强。
*   **实验严谨全面**：消融实验设计精良，能够清晰归因；鲁棒性测试考虑了实际场景；在多个权威基准上进行了验证。
*   **软门控机制**：SpatialGate使用可学习的MLP生成软门控，避免了硬边界伪影，并能吸收一定的掩码标注噪声。

## 8. 不足与局限
*   **对全局编辑效果有限**：方法的核心假设是编辑具有明确的空间范围。对于全局风格化、无明确源区域的几何编辑或多对象同时编辑，其优势减弱，甚至需要关闭适配器回退到原始骨干网络。
*   **单掩码假设**：当前设计假设每次编辑对应一个单一的二值掩码。对于需要分离多个独立区域的复杂编辑，需要扩展。
*   **继承骨干网络偏差**：REDEdit继承了其骨干网络（Qwen-Image-Edit）在训练数据中存在的偏差（如光照、种族、产品类别分布），且自身无法纠正。
*   **训练成本较高**：尽管可训练参数不多，但由于需要运行完整的骨干网络前向传播，单步训练显存需求很高（~70-78GB），限制了其在消费级硬件上的使用。
*   **MaskPredictor的局限性**：对于没有明确空间范围的指令（如“让照片更暖”），掩码预测器会失效，此时需要回退到无适配器模式。
