## 摘要
大型扩散变换器（DiTs）能很好地遵循全局编辑指令，但总是将局部编辑泄漏到不相关区域，因为联合注意力架构没有提供明确的通道来告诉网络在哪里应用编辑。我们引入AdaptEdit，一个共同训练的、指令和区域感知的适配器框架，它将冻结的DiT改装成精确的局部编辑器，而不修改其骨干权重。在每个变换器块中，一个轻量级的Block Adapter注入一个结构化条件流，将编辑什么（指令语义）与在哪里编辑（空间掩码）分离；一个学习的SpatialGate选择性地将适配器信号路由到编辑区域，同时保持图像的其余部分与源图像几乎相同；一个Region-Aware Loss将训练目标聚焦在变化的像素上。因为这些组件使骨干的内部表示端到端地感知掩码，一个与编辑器共同训练的薄MaskPredictor头可以直接从指令和源图像中定位编辑区域——消除了部署时对用户掩码的任何要求。我们在两个互补的基准上进行评估：MagicBrush（配对的真实目标）用于测量像素级保留和编辑准确性，以及Emu-Edit Test（无真实图像，9种多样编辑类别）用于压力测试指令遵循和跨编辑类型的泛化。在两者上，AdaptEdit都达到了最先进的结果，同时超越了无遮罩和神谕掩码基线。一个七变体消融实验清晰地隔离了每个组件的贡献。

## Abstract
Large diffusion transformers (DiTs) follow global editing instructions well but consistently leak local edits into unrelated regions, because joint-attention architectures offer no explicit channel telling the network where to apply the edit. We introduce AdaptEdit, a co-trained, instruction- and region-aware adapter framework that retro-fits a frozen DiT into a precise local editor without modifying its backbone weights. A lightweight Block Adapter at every transformer block injects a structured condition stream that factorizes what to edit (instruction semantics) from where to edit (spatial mask); a learned SpatialGate routes the adapter signal selectively into the edit region while keeping the rest of the image near-identical to the source; and a Region-Aware Loss focuses the training objective on the changing pixels. Because these components make the backbone's internal representation mask-aware end-to-end, a thin MaskPredictor head trained jointly with the editor can ground the edit region directly from the instruction and source image -- eliminating any user-mask requirement at deployment. We evaluate on two complementary benchmarks: MagicBrush (paired ground-truth targets) to measure pixel-level preservation and edit accuracy, and Emu-Edit Test (no ground-truth images, 9 diverse edit categories) to stress-test instruction following and generalization across edit types. On both, AdaptEdit achieves state-of-the-art results, simultaneously outperforming mask-free and oracle-mask baselines. A seven-variant ablation cleanly isolates the contribution of each component.

## 1. 核心问题与整体含义
*   **研究动机**：当前基于大型扩散变换器（DiTs）的指令驱动图像编辑模型，在处理局部编辑（如“将杯子改为红色”）时，编辑效果会“泄漏”到无关区域（如桌子、背景）。这是因为主流的联合注意力架构缺乏一个明确的、用于指定编辑空间位置的通道。
*   **背景与现状**：现有方法主要分为两类：1) **指令驱动模型**（如InstructPix2Pix, Emu-Edit），依赖全局注意力融合指令，易导致编辑泄漏；2) **掩码条件模型**（如BrushNet），需要用户提供精确的像素级掩码，不适用于大规模迭代工作流。两者均无法在无需用户干预的情况下实现精确、无泄漏的局部编辑。
*   **整体含义**：本文旨在解决这一核心矛盾，提出一种无需用户掩码、能精确控制编辑区域、且不修改庞大骨干网络权重的高效适配方案，以满足电商、广告等工业场景对精准局部编辑的需求。

## 2. 方法论
*   **核心思想**：将冻结的大型DiT骨干网络改造为精确的局部编辑器。关键在于通过一个协同训练的适配器框架，显式地将“编辑什么”（指令语义）与“在哪里编辑”（空间位置）解耦并注入网络。
*   **关键技术细节**：
    1.  **Block Adapter**：在DiT的每个Transformer块中插入一个轻量级交叉注意力适配器。它接收一个结构化的条件流，并通过门控残差将适配器信号注入骨干网络的输出。
    2.  **Condition Encoder**：将编辑掩码和指令文本编码为结构化的条件流。它包含：
        *   **掩码空间编码器**：将二值掩码下采样后，通过两个可学习嵌入向量的插值转换为离散的“编辑/保留”标记。
        *   **指令感知投影器**：使用Perceiver风格的交叉注意力，将多层视觉语言模型（VL）的隐藏状态压缩为固定数量的语义标记。
        *   **融合模块**：通过一个小型Transformer融合空间标记和语义标记，使“位置”信息与“内容”信息交互。
    3.  **SpatialGate**：为每个潜在标记生成一个软门控值（0到1）。它基于下采样的掩码，通过一个小型MLP学习生成。在编辑区域内门控值接近1，允许适配器信号完全修改潜在表示；在区域外接近0，使该区域输出与原始骨干网络一致，从而实现无缝、精确的局部编辑。
    4.  **Region-Aware Loss**：在标准的速度预测损失基础上，根据掩码对损失进行加权。对变化区域的像素赋予更高权重（α=2），迫使模型专注于学习编辑区域，同时仍对非编辑区域的泄漏施加惩罚。
    5.  **MaskPredictor**：一个轻量级的头部网络，与编辑器联合训练。它在推理时直接从源图像和文本指令中预测编辑区域掩码，从而**完全消除了对用户输入掩码的依赖**。训练采用“解耦”策略：编辑路径始终使用真实掩码，MaskPredictor则通过独立的BCE+Dice损失进行监督，避免了耦合训练中的自我强化失败模式。

## 6. 主要结论与发现
*   **性能领先**：AdaptEdit在MagicBrush和Emu-Edit Test上均达到了最先进的结果，在像素保留（L1）和视觉相似性（CLIP-I, DINO）上显著优于所有无掩码和神谕掩码基线。

*   **无掩码可行性**：通过协同训练的MaskPredictor，模型能够在推理时仅凭源图像和指令准确预测编辑区域，实现了完全无用户掩码的精确局部编辑。
*   **设计合理性**：将“编辑什么”与“在哪里编辑”解耦并通过软门控注入的设计，是解决编辑泄漏问题的有效途径。

## 7. 优点
*   **方法创新**：提出了一个完整、协同工作的框架，首次在大型DiT上实现了指令感知、区域感知的适配器注入，显式引入了空间控制通道。
*   **参数高效**：仅需训练约25%的额外参数，且骨干网络完全冻结，降低了训练成本和对预训练知识的破坏风险。
*   **实用性强**：推理时无需用户掩码，简化了工作流，更贴近实际应用需求。
*   **实验严谨**：消融实验设计系统，能够清晰归因；评估全面，涵盖了多个权威基准和多种评估维度。
*   **组件设计精巧**：如SpatialGate的软门控避免了边界伪影，Condition Encoder的解耦与融合设计，以及MaskPredictor的解耦训练策略，都体现了对问题的深入思考。

## 8. 不足与局限
*   **应用场景限制**：方法主要针对具有明确空间范围的局部编辑。对于**全局编辑**（如风格迁移）、**几何变化大且无源区域**的编辑、或**多对象同时编辑**，效果可能不佳或需要回退到未适配的骨干网络。
*   **单掩码假设**：当前设计假设每次编辑对应一个二值掩码。对于需要多个独立区域分别编辑的复杂指令，需要扩展。
*   **继承骨干偏见**：模型继承了骨干网络（Qwen-Image-Edit）在训练数据中存在的偏见（如光照、种族、产品类别分布），且未进行纠正。
*   **MaskPredictor的局限性**：对于没有明确空间范围的指令（如“让照片更暖”），MaskPredictor的预测会失效，此时需回退。
*   **算力要求高**：尽管参数高效，但前向传播仍需完整的骨干网络，对显存要求较高（>70GB），限制了其在消费级硬件上的使用。
*   **训练数据偏差**：训练数据集中于局部编辑任务，缺乏全局编辑样本，这可能导致模型在全局编辑任务上的泛化能力未经充分验证。
