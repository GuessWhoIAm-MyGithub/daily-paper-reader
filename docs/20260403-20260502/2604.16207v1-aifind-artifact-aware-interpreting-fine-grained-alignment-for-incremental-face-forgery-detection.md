## 摘要
随着伪造类型不断涌现，增量人脸伪造检测（IFFD）已成为一个关键范式。然而，现有方法通常依赖于数据重放或粗粒度二元监督，这未能显式约束特征空间，导致严重的特征漂移和灾难性遗忘。为了解决这个问题，我们提出了AIFIND，即用于增量人脸伪造检测的伪影感知解释细粒度对齐，它利用语义锚点来稳定增量学习。我们设计了伪影驱动语义先验生成器来实例化不变的语义锚点，从低级伪影线索建立固定的坐标系。这些锚点通过伪影探针注意力注入图像编码器，显式约束易变的视觉特征以与稳定的语义锚点对齐。自适应决策协调器通过保持语义锚点的角度关系来协调分类器，维持跨任务的几何一致性。在多个增量协议上的广泛实验验证了AIFIND的优越性。

## Abstract
As forgery types continue to emerge consistently, Incremental Face Forgery Detection (IFFD) has become a crucial paradigm. However, existing methods typically rely on data replay or coarse binary supervision, which fails to explicitly constrain the feature space, leading to severe feature drift and catastrophic forgetting. To address this, we propose AIFIND, Artifact-Aware Interpreting Fine-Grained Alignment for Incremental Face Forgery Detection, which leverages semantic anchors to stabilize incremental learning. We design the Artifact-Driven Semantic Prior Generator to instantiate invariant semantic anchors, establishing a fixed coordinate system from low-level artifact cues. These anchors are injected into the image encoder via Artifact-Probe Attention, which explicitly constrains volatile visual features to align with stable semantic anchors. Adaptive Decision Harmonizer harmonizes the classifiers by preserving angular relationships of semantic anchors, maintaining geometric consistency across tasks. Extensive experiments on multiple incremental protocols validate the superiority of AIFIND.

### 1. 核心问题与整体含义
- **研究背景**：随着深度伪造技术的快速演进，静态训练的检测模型很快会失效。增量人脸伪造检测（IFFD）旨在让模型持续学习新的伪造类型，同时保留对旧类型的知识。
- **核心问题**：现有IFFD方法主要依赖**数据重放**（存储部分旧数据）或**粗粒度二元监督**（仅区分真假）。这导致两个关键缺陷：
    1.  **特征漂移与灾难性遗忘**：缺乏对特征空间的显式约束，学习新任务时容易覆盖旧知识。
    2.  **忽略细粒度线索**：将伪造视为单一类别，无法利用不同伪造类型特有的、细微的伪影（如眼睛模糊、光照不一致）作为稳定学习的锚点。
- **论文含义**：本文旨在提出一种**无需数据重放**的框架，通过将**伪影（Artifact）转化为稳定的语义锚点**，显式约束特征空间，从而在增量学习中实现稳定、可解释且细粒度的伪造检测。

### 2. 方法论
- **核心思想**：利用预训练视觉语言模型（VLM，如CLIP）对语义的敏感性，将低级视觉伪影与高级文本描述关联，构建一个**不变的语义锚点库**。在增量学习中，持续将易变的视觉特征对齐到这些稳定的语义坐标上。
- **关键技术细节**：
    - **伪影驱动语义先验生成器（ASPG）**：
        - 定义5个伪影维度（模糊、颜色、结构、纹理、边界）和6个面部区域。
        - 利用传统图像处理指标（如拉普拉斯方差、SSIM）量化每个区域的伪影严重度。
        - 使用大语言模型（LLM）为每个“区域-维度”组合生成对比性文本对（真实描述 vs. 伪造描述）。
        - 通过CLIP相似度从候选集中筛选最优文本对，构建**语义锚点库**。
    - **语义引导增量检测器（SGID）**：
        - **伪影探针注意力（APA）**：在图像编码器（ViT）的高层注入跨模态注意力模块。以视觉特征为查询（Query），匹配到的语义锚点文本嵌入为键值（Key/Value），实现细粒度视觉-文本对齐。使用可学习的门控机制动态调节语义信息的注入强度。
        - **双重监督**：同时训练一个二元分类头（真假）和一个**多标签分类头**（预测具体存在哪些伪影类型）。损失函数包含交叉熵损失和二元交叉熵损失。
    - **自适应决策协调器（ADH）**：
        - 为解决分类器权重在增量过程中的漂移问题，提出**球面语义对齐**方法。

        - 在超球面上，沿测地线将当前权重向参考向量旋转，对齐决策边界的方向，同时保持权重范数不变，以维持判别力。
    - **训练策略**：初始阶段使用固定的语义锚点进行预热，之后激活**动态匹配**机制，根据视觉特征与文本嵌入的相似度自适应检索最相关的锚点。
